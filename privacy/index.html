The extension

Tab Attic reads the address, title and tab-group name of your open tabs and remembers when each was last viewed, so it can tell which tabs are idle. For tabs it archives, it stores the address, title, archive time and topic.

Everything is stored on your computer: in the extension's own database in your browser and in your Chrome bookmarks (Other bookmarks › Tab Attic). If you use Chrome Sync, Chrome syncs those bookmarks and the extension's settings, as it does for all bookmarks and extension settings.

Grouping by meaning uses the model built into Chrome (Gemini Nano), which runs on your device. Tab titles aren't sent anywhere.

If you turn on “Keep tabs with unsent text” (off by default), the extension checks whether a page has text typed into a form. It reads only whether such text exists, never the text itself.

The extension has no server, no analytics and no ads. It doesn't sell or transfer data and doesn't load remote code.

Links that open this website

Links in the extension are ordinary links: they open this website only when you click them. When the extension is removed, Chrome opens a short survey page on this website; its address includes the extension's version number and nothing else.

This website

We count page visits with Cloudflare Web Analytics, which doesn't use cookies and doesn't build profiles of visitors. We see totals such as the number of visits to a page and where visitors came from.
