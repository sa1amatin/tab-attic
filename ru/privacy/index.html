Расширение

Tab Attic читает адрес, заголовок и название группы открытых вкладок. Ещё он запоминает время последнего просмотра каждой вкладки и так находит неактивные. Для убранных вкладок хранятся адрес, заголовок, время и тема.

Всё хранится на вашем компьютере: в базе расширения в браузере и в ваших закладках Chrome («Другие закладки › Tab Attic»). Синхронизация Chrome переносит эти закладки и настройки расширения вместе с остальными.

Группировку по смыслу выполняет встроенная в Chrome модель Gemini Nano прямо на вашем устройстве. Заголовки вкладок никуда не отправляются.

Настройка «Не закрывать вкладки с недописанным текстом» по умолчанию выключена. После её включения расширение проверяет наличие введённого в форму текста. Сам текст оно не читает.

У расширения нет сервера, аналитики и рекламы. Оно не продаёт и не передаёт данные и не загружает удалённый код.

Ссылки на этот сайт

Ссылки в расширении - обычные ссылки. Сайт открывается только по вашему нажатию. После удаления расширения Chrome открывает на этом сайте страницу с коротким опросом. В её адресе есть только номер версии расширения.

Этот сайт

Посещения считает Cloudflare Web Analytics без cookie и без профилей посетителей. Мы видим только общие цифры: число просмотров страницы и источники переходов.

Ответы в опросе при удалении помогают решить, что делать дальше. Формы обрабатывает наш сервис форм. Для удаления ответов напишите на адрес ниже.
